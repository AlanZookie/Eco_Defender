# Eco Defender

Eco Defender is an educational game that combines entertainment with environmental awareness. The game features multiple mini-games and interactive elements designed to teach players about climate change, environmental conservation, and sustainable practices.

## Features

- **Multiple Game Modes**:
  - Puzzle Game: Solve environmental-themed puzzles
  - Shooting Game: Defend the environment from pollution
  - Graphical Mode: Interactive visual experience
  - Text Mode: Story-driven narrative (coming soon)

- **Educational Content**:
  - Climate change awareness
  - Environmental conservation tips
  - Sustainable practices
  - Interactive learning through gameplay

- **Technical Features**:
  - Pygame-based graphics
  - Event-driven architecture
  - Configurable settings
  - Progress tracking and statistics

## Installation

1. Ensure you have Python 3.x installed on your system
2. Install the required dependencies:
   ```bash
   pip install pygame
   ```
3. Clone this repository:
   ```bash
   git clone [repository-url]
   ```
4. Navigate to the project directory:
   ```bash
   cd Eco_Defender
   ```

## Running the Game

1. Start the game by running:
   ```bash
   python src/main.py
   ```
2. Use the start menu to select your preferred game mode
3. Follow the on-screen instructions to play

## Project Structure

```
Eco_Defender/
├── assets/          # Game assets (images, sounds, etc.)
├── config/          # Configuration files
│   ├── plot.py     # Story and plot configuration
│   ├── stats.py    # Statistics configuration
│   └── instro.txt  # Game instructions
└── src/            # Source code
    ├── main.py              # Entry point
    ├── start_menu.py        # Start menu interface
    ├── graphical_mode.py    # Graphical game mode
    ├── puzzle_game.py       # Puzzle mini-game
    ├── shooting_game.py     # Shooting mini-game
    ├── event_manager.py     # Event handling
    ├── background_manager.py # Background management
    ├── plot_manager.py      # Story progression
    ├── stats_manager.py     # Statistics tracking
    └── climate_manager.py   # Climate-related mechanics
```

## Controls

- **Menu Navigation**: Mouse
- **Puzzle Game**: Mouse for dragging and placing pieces
- **Shooting Game**: 
  - Arrow keys for movement
  - Space bar for shooting
  - Mouse for aiming
